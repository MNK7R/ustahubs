UstaHub - ishga tushirish

1. cd backend
2. npm install
3. (ixtiyoriy) .env.example faylni .env ga nusxalab, JWT_SECRET va admin parolini almashtiring
4. npm start
5. Brauzerda oching: http://localhost:3000

MUHIM: saytni index.html ni ikki marta bosib yoki Live Server orqali ochmang -
faqat yuqoridagi manzil (http://localhost:3000) orqali oching, aks holda API ishlamaydi.

Admin panel: "Boshliq paneli" tabi. "Bajarildi" tugmasi buyurtmani yopib, ustani bo'shatadi.
